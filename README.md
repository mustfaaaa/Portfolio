# Developer Portfolio

A production-ready, single-page developer portfolio built with Next.js, TypeScript, Tailwind CSS, Radix UI, shadcn-style components, and Motion.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Edit your content

All personal content lives in `src/data/portfolio.ts`. Update that file to replace the clearly labeled placeholders for your name, contact details, projects, experience, education, certifications, achievements, testimonials, and articles.

## Quality checks

```bash
npm run lint
npm run build
```

## Deploy

Import the repository into Vercel. The project uses the standard Next.js build command and requires no environment variables, database, or backend service.
